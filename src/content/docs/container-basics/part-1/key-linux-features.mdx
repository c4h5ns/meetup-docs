title: Linuxの重要機能
---

## `namespace`
プロセスを隔離し、他のプロセスが見えないようにする
- PID: プロセスID（PID）を隔離する。
  コンテナ内で最初に起動されるプロセス（エントリポイント）にとって、
  自分自身の `PID = 1` のように見せる。
- Network: ネットワーク（IPアドレス、ポート、ルーティング）を独立させる。
- Mount: 見えるファイルシステム（ディレクトリツリー）を隔離する
- ユーザー権限
- ホスト名
- プロセス間通信
- etc...

## `cgroups` (Control Groups)
プロセスが使用できるハードウェアリソースを制限
- CPU: コンテナが使えるCPUコア数や使用率を制限
- Memory: 使用可能なメモリを制限
- Block I/O: ディスクの読み書き速度を制限

## `overlayfs` (Overlay File System)
ベースとなるファイルツリーを「読み取り専用」として保持し、変更時には差分のみを保存する

## その他セキュリティ関連の技術
- **Linux Capabilities**  
  `root` 権限をさらに差分化し、不要な特権を剥奪（Drop）する
- **`seccomp` (Security Computing Mode)**  
  プロセスが呼び出せるシステムコールを制限する
- **AppArmor** / **SELinux**  
  プロセスごとにアクセス制御ルール（プロファイル）を適用する、強制アクセス制御（MAC: Mandatory Access Control）機能
